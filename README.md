# DMC Staff Analytics

ระบบวิเคราะห์ข้อมูลบัญชีเจ้าหน้าที่จากไฟล์ HTML ที่ส่งออกจากระบบ DMC Staff เพื่อช่วยตรวจสอบการเข้าใช้งานล่าสุดและความครบถ้วนของบัญชีผู้ใช้งานในแต่ละโรงเรียน

**เว็บไซต์:** https://b32bit.github.io/dmc-staff/  
**Repository:** https://github.com/b32bit/dmc-staff

## ความสามารถของระบบ

- นำเข้าไฟล์ข้อมูล HTML จากระบบ DMC Staff โดยเลือกไฟล์หรือลากไฟล์มาวาง
- สรุปจำนวนบัญชีผู้ใช้งานและจำนวนโรงเรียน
- วิเคราะห์สถานะการ Login ล่าสุดตามช่วงวันที่กำหนด
- แสดงภาพรวมสถานะ Login และแยกตามกลุ่มผู้ใช้งาน
- ตรวจสอบความครบถ้วนของบทบาทผู้ใช้งานรายโรงเรียน ได้แก่
  - `SCHOOL_DIRECTOR`
  - `SCHOOL_MANAGER`
- ค้นหาและกรองข้อมูลโรงเรียนตามเงื่อนไข
- ค้นหาและกรองบัญชีตาม Username ชื่อ-นามสกุล โรงเรียน กลุ่มผู้ใช้งาน และสถานะ Login
- เรียงลำดับข้อมูลและกำหนดจำนวนรายการต่อหน้า
- ส่งออกผลการวิเคราะห์เป็นไฟล์ CSV ทั้งระดับโรงเรียนและระดับบัญชี

## วิธีใช้งาน

1. เปิดเว็บไซต์ [DMC Staff Analytics](https://b32bit.github.io/dmc-staff/)
2. เตรียมไฟล์ HTML ที่ส่งออกหรือบันทึกจากระบบ DMC Staff
3. เลือกไฟล์ HTML หรือ拖ลากไฟล์มาวางในพื้นที่นำเข้า
4. รอระบบอ่านและวิเคราะห์ข้อมูล
5. เมื่อประมวลผลสำเร็จ ส่วน **1. นำเข้าไฟล์ข้อมูล** จะถูกซ่อน และระบบจะแสดงผลการวิเคราะห์
6. ใช้ช่องค้นหาและตัวกรองเพื่อดูข้อมูลที่ต้องการ
7. เลือกส่งออก CSV เมื่อต้องการนำผลไปใช้งานต่อ

> หากนำเข้าไฟล์ไม่สำเร็จ ระบบจะแสดงข้อความแจ้งข้อผิดพลาด และยังคงแสดงส่วนสำหรับเลือกไฟล์เพื่อให้ลองใหม่

## เกณฑ์การวิเคราะห์สถานะ Login

ระบบคำนวณจำนวนวันจากวันที่ Login ล่าสุดจนถึงวันที่เปิดใช้งานระบบ แล้วจัดกลุ่มสถานะดังนี้

| สถานะ | เงื่อนไข |
|---|---|
| ปกติ | Login ภายใน 7 วัน |
| ติดตาม | มากกว่า 7 วัน ถึง 30 วัน |
| ควรตรวจสอบ | มากกว่า 30 วัน ถึง 90 วัน |
| ผิดปกติ | มากกว่า 90 วัน |
| ไม่มีข้อมูล | ไม่มีวันที่ Login หรือไม่สามารถอ่านวันที่ได้ |

วันที่ Login ที่อยู่ในอนาคตจะถูกจัดเป็นสถานะ **ปกติ** ตามเงื่อนไขของระบบในปัจจุบัน

## การตรวจสอบความครบถ้วนรายโรงเรียน

ระบบรวบรวมบัญชีตามชื่อโรงเรียนที่ปรากฏในไฟล์ และนับจำนวนบัญชีตามบทบาทผู้ใช้งาน

- **ครบ:** พบทั้ง `SCHOOL_DIRECTOR` และ `SCHOOL_MANAGER`
- **ขาดบทบาท:** ไม่พบบทบาทใดบทบาทหนึ่ง หรือไม่พบบทบาททั้งสอง

นอกจากนี้ยังแสดงจำนวนบัญชีในแต่ละสถานะ Login และวันที่ Login ล่าสุดของโรงเรียน

## รูปแบบไฟล์นำเข้า

ระบบรองรับไฟล์นามสกุล `.html` และ `.htm` ซึ่งมีตารางข้อมูล Staff โดยต้องมีคอลัมน์สำคัญอย่างน้อย ได้แก่

- Username
- กลุ่มผู้ใช้งาน
- โรงเรียน
- เวลา Login ล่าสุด

ระบบจะอ่านคอลัมน์ชื่อ นามสกุล เขตพื้นที่การศึกษา และหมายเลขโทรศัพท์มือถือเพิ่มเติมเมื่อมีอยู่ในไฟล์

หากโครงสร้างตารางหรือชื่อคอลัมน์ไม่ตรงกับรูปแบบที่ระบบรองรับ อาจไม่สามารถนำเข้าข้อมูลได้

## ความเป็นส่วนตัวและการจัดเก็บข้อมูล

- ประมวลผลข้อมูลภายในเว็บเบราว์เซอร์ของผู้ใช้งาน
- ไม่มีการส่งไฟล์นำเข้าไปยังเซิร์ฟเวอร์
- ไม่มีระบบบัญชีผู้ใช้หรือฐานข้อมูลส่วนกลาง
- ไม่มีการบันทึกข้อมูลลง `localStorage`
- เมื่อรีเฟรชหรือปิดหน้าเว็บ ข้อมูลที่นำเข้าจะหายไป ต้องนำเข้าไฟล์ใหม่เมื่อต้องการใช้งานอีกครั้ง

**ข้อควรระวัง:** ไฟล์ DMC Staff อาจมีข้อมูลส่วนบุคคล เช่น ชื่อ-นามสกุล หมายเลขโทรศัพท์ และบัญชีผู้ใช้งาน ควรเก็บรักษาไฟล์ต้นฉบับและไฟล์ CSV ที่ส่งออกอย่างเหมาะสม และเผยแพร่เฉพาะข้อมูลที่ได้รับอนุญาต

## เทคโนโลยี

- HTML5
- CSS3
- JavaScript (Vanilla JavaScript)
- Browser DOMParser และ File API

ระบบเป็นเว็บแอปพลิเคชันแบบ Static ไม่จำเป็นต้องติดตั้ง Backend หรือฐานข้อมูล
